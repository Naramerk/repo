Одна задача: вызвать инструмент static:ping и сохранить результат.

Требования к плану:
- ровно одна задача (route "experiment"), tools_hint ровно ["static:ping"];
- у задачи один ожидаемый выход: имя "static:ping" (совпадает с именем вызванного инструмента: артефакт результата инструмента и есть этот выход), media_type "application/json", required, с рубрикой из одного пункта (check "code", code_kind "artifact_exists", required);
- criteria задачи — пустой список [] (criteria принимает только id шаблонов каталога проверок; проверка "artifact_present" будет подставлена автоматически);
- ровно один вопрос (final_type "artifact"), на который отвечает эта задача;
- гипотезы не нужны (hypotheses.needed = false), литература не нужна (literature.needed = false).

Исполнитель задачи: tool_found = ["static:ping"]; values — пустой массив [] (артефакт результата инструмента записывается автоматически).
